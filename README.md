# The One-Line Laugh

One funny line, a single sentence of at most 200 characters, written by
`main.ts` to `/output/entry.txt` for the make.fun bounty
[The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

The line: "My plant died, so I bought a fake one, and now I water it out of guilt."

Run with Node 22: `node main.ts` (writes `/output/entry.txt`, or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
